## Before you cancel — 60 seconds

1. Note **next bill date** and **annual vs monthly**.
2. Export any data (Notion, password vault, photos).
3. Screenshot the **current price** line — proof if they “win back” with a fake discount.

## Amazon (digital + channels + S&S)

| What | Path |
|------|------|
| Prime Video channel | Account → **Memberships & subscriptions** → channel → Cancel |
| Audible / KU / Music | Same hub — confirm **end of period** |
| Subscribe & Save | **Subscribe & Save items** → Cancel or skip |
| Unknown charges | [Subscription creep walkthrough](/articles/amazon-subscription-creep) |

## Apple / Google

- **iPhone:** Settings → your name → **Subscriptions**
- **Android:** Play Store → profile → **Payments & subscriptions**

Family-shared subs: see [family subscriptions](/pillars/family-subscriptions) before removing a kid’s access.

## Netflix / Max / Disney+

Account website (not always in TV app) → **Cancel membership** → finish confirmation screen → email PDF.

Set calendar for **one day before** trial end; most trials bill at **local midnight**.

## SaaS (Notion, Canva, VPN)

1. Profile → **Billing**
2. Downgrade to free **first** if cancel button hidden
3. Open support ticket if annual refund window applies (often 14–30 days)

## When cancel fails

- Card issuer **recurring charge dispute** — last resort; document prior cancel attempts.
- Replace card number only for rogue merchants — heavy-handed, works.
